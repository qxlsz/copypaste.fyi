# Code of conduct

This project follows a short, operational conduct rule: be precise, be kind,
and do not use the software to harm people.

- Assume contributors are acting in good faith.
- No harassment, legal threats as a first resort, or doxxing.
- Security issues go to the contact in `docs/SECURITY.md`, not the public issue
  tracker, until there is a fix or a coordinated disclosure date.
- Pastes that violate `ACCEPTABLE_USE.md` should be quarantined by exact id.

Maintainers may refuse changes, close issues, or quarantine ids that conflict
with those rules.
